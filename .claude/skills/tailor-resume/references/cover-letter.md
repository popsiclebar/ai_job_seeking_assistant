# Cover letters and application emails

Read this when the role asks for a cover letter, a "personligt brev", or applying by email.

## Cover letter (one page, ~250–330 words, four paragraphs)

Copy the template's HTML, replace the letter-meta block through the signature, and update the header
comment and `<title>`. Use the header name and signature format given in the evidence file.

1. **Opening** — the exact role and team, and one specific reason this role/company fits. Quote or paraphrase
   something concrete from the ad, not generic praise.
2. **Evidence** — one or two examples that answer the ad's main need, told as what was built and what was
   learned. Don't repeat the resume line by line.
3. **Gap or motivation** — if there is an obvious gap the ad names (e.g. on-prem storage, Swedish, years of
   experience), acknowledge it briefly and turn it into a concrete learning intent when the ad invites
   that. Otherwise, connect the candidate's working style to the team's real context.
4. **Close** — the logistics line from the evidence file (location, work authorization, availability),
   an invitation to talk, and thanks.

Tone: plain, specific, confident without superlatives. British/neutral English is fine.

## Application email (when applying by email)

Subject: `Application – <Role>, <Company> (<display name>)`. Body under ~150 words: greet the named contact,
state the role and that the CV is attached, one short paragraph of the most relevant evidence, logistics
line (from the evidence file), GitHub link, sign-off with name and phone. Create it as an
Outlook draft only; the user attaches the PDF and sends.
